### 10.2 Phonetic Analysis Depth
- **Full IPA analysis**: Most rigorous, most labor-intensive
- **Simplified features**: Faster, may miss subtleties
- **Hybrid**: Full analysis for core concepts, simplified for expansion

**Recommendation**: Full analysis for first 50 concepts, develop simplified system from patterns discovered.

### 10.3 Cross-Linguistic Validation
- **English only**: Faster, but may encode English-specific features
- **Multiple languages**: More universal, but vastly more work
- **Core + validation**: English encoding, spot-check against other languages

**Recommendation**: English primary, Korean secondary (we have the infrastructure), validate key concepts across 3-5 more languages.

### 10.4 Handling Polysemy
- **Multiple positions**: "Bank" (river) and "bank" (financial) are different entries
- **Superposition**: Single encoding that collapses in context
- **Core + context**: Base position + contextual modifiers

**Recommendation**: Start with core meanings only. Address polysemy after foundation is solid.
