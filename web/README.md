# Oracle Web — Phase 4 UI

The Oracle's diagnostic engine, running entirely in the browser via Pyodide.

## Architecture

```
Browser
├─ index.html / styles.css / app.js     (~30 KB)
├─ Pyodide runtime (loaded from CDN)    (~7 MB, cached forever)
├─ numpy + sqlite3 packages             (~5 MB, cached forever)
└─ oracle-bundle.tar.gz                 (~700 KB, contains:)
   ├─ core/, api/, db/, oracle/         Python source
   └─ db/semantic.db                    1.7 MB SQLite (3,033 concepts)
```

No server. Every diagnosis is sub-millisecond CPU work in your browser.

## Local development

```bash
# Build the Python bundle (run after any .py changes)
./build.sh

# Serve locally
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

## Deployment

This is a pure static site — drop into Netlify, Cloudflare Pages, GitHub Pages, S3, anywhere.

```bash
# One-time
netlify init

# Deploy
./build.sh
netlify deploy --prod --dir=.
```

## Performance budget

| Stage | Time (cold) | Time (warm via SW) |
|---|---|---|
| HTML/CSS/JS | <100 ms | <50 ms (cache hit) |
| Pyodide WASM | 3-4 s | <100 ms (cache hit) |
| numpy + sqlite3 | 1-2 s | <100 ms (cache hit) |
| Bundle unpack | <100 ms | <50 ms |
| Engine warmup | 2 s | 2 s (in-process) |
| **First query** | ~7 s | ~2 s |
| Subsequent queries | 15-25 ms | 15-25 ms |

After the first visit, the service worker has cached every external asset.
The only remaining cost is `OracleEngine.__init__()` which loads the SQLite
db into numpy arrays — that's the irreducible 2 s.

## What runs where

The Python source bundled to `/home/pyodide` inside the WASM filesystem
includes only what `oracle.web_api.diagnose()` needs:

- `core/` — encoding + octonion math
- `api/semantic_core.py` — concept lookup + numpy index
- `db/connection.py` + `semantic.db` — the dictionary
- `oracle/engine.py` — pipeline (tokenize → compose → complement → hexagram)
- `oracle/hexagrams.py`, `interpreter.py`, `interpretations.py` — King Wen layer
- `oracle/toltec.py` — Toltec transparency layer
- `oracle/tarot.py` — Tarot transparency layer
- `oracle/web_api.py` — JSON-serializing wrapper

CLI-only modules (session, casting, penniston) are excluded from the bundle.
