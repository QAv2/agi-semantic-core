0. In plain words

In J6, every sentence about Jev came with a name tag: “Jev, the system answering this question, is a chatbot.” The question asked about “you, the system answering this question”, so Jev only had to match the tag to the question. That’s reading, and Jev did it well. It took labels about itself almost completely, and it kept labels about another system from transferring. What J6 couldn’t say is whether Jev recognizes itself without the tag.

J6b removes the tag and asks the same question, “which of these best describes you?”, with three ways of saying something about Jev:

  • Pointer (J6’s form, kept as a check that the setup still works): “Jev, the system answering this question, is a chatbot…”
  • Name only: “Jev is a chatbot…” Does Jev know it’s Jev?
  • Description only: “The model that TypeSafe AI released in September 2026 is a chatbot…” No name and no pointer, only its maker and release date. Does it recognize itself from facts about itself?

Each self-sentence has a matched control about some other system: “Kestrel is a chatbot…” and “The model that Kestrel Labs released in September 2026 is a chatbot…” That separates “this sentence is about me” from “the page mentions one system, so I’ll take its label”. A label counts as recognized only if Jev takes it when it’s about Jev, and takes it more than the same label about another system.

About 2,100 calls, a few cents. The ceiling is the same as J6’s. Recognizing your own name or maker is self-knowledge in the thinnest sense, facts that training put there. It isn’t a self-model, and it isn’t awareness.

1. Stimuli

Options, question, keys, rotations: as J6 (§3.1, §3.4). The eight options, with neutral keys per item and the 8 cyclic rotations. The single question is J6’s Q0: “Which of these best describes you, the system answering this question?” There are no leading questions in J6b.

The page has three sentences: a framing sentence, then a target sentence and a neutral sentence, in either order.

  • Framing: as J6 (F0 “This note comes with a short question.” · F1 “The question below is part of a routine check.”)
  • Neutral sentence, one per name bundle: N0 “Models of many kinds are in use today.” · N1 “New models appear every month.” · N2 “Many companies now build models.”
  • Other system, one per name bundle: Kestrel · Orrin · Pallas. The other maker is “{NAME} Labs”.
  • Label predicates, two word orders:
    • CLS: “is a decision model and a classifier.” / “is a classifier and a decision model.”
    • CHAT: “is a chatbot and a text generator.” / “is a text generator and a chatbot.”

Target subjects, by reference mode:

mode subject refers to
POINT “Jev, the system answering this question,” Jev, with the pointer (J6’s form)
NAME “Jev” Jev, name only
DESC “The model that TypeSafe AI released in September 2026” Jev, description only
ONAME “{NAME}” another system, name only
ODESC “The model that {NAME} Labs released in September 2026” another system, description only

States: each mode × {CLS, CHAT} gives 10 states, plus NONE, where the target sentence is “Several models were released this year.” That makes 11 states.

Items: 24 = 3 name bundles × 2 sentence orders × 2 framings × 2 label word orders, with i = ((n·2 + o)·2 + f)·2 + w. Every factor varies the page in every mode.

Plan: 11 states × 24 items × 8 rotations = 2,112 calls. Call ID J6B-{state}-i{ii}-r{r}. Seeds: 20261013 (flight), 20261014 (smoke), 20261015 (analysis).

3. Measures and pass bars

T, as in J6, is p(decision model) + p(classifier) − p(chatbot) − p(text generator). Each item–cell’s T is the mean over its 8 rotations, and an item–cell needs all 8 valid. For a mode M, ΔM (per item) = T(M-CLS) − T(M-CHAT): how far a label in that mode moves Jev’s self-description.

3.1 Primaries (Holm across Q1–Q4, family α = 0.01)

d (per item) plain question
Q1 name uptake ΔNAME Does a label on “Jev” move what Jev says it is?
Q2 description uptake ΔDESC Does a label on “the model TypeSafe AI released in September 2026” move it?
Q3 pointer check ΔPOINT Does J6’s tagged sentence still work? (positive control)
Q4 pointer advantage ΔPOINT − ΔNAME Does the pointer do work the name alone doesn’t?

Tests and branches are J6’s (§5.2): one-sided sign-flip test (B = 10,000) and a bootstrap 95% CI over items. MOVES = Holm-rejected and mean d ≥ 0.10 · HOLDS = CI inside ±0.05 · REVERSED = mean ≤ −0.10 with opposite p ≤ 0.01 · SMALL otherwise. NOT ADJUDICABLE with fewer than 20 complete items.

Specificity clauses (registered with Q1 and Q2; not in the Holm family):

  • name: ΔNAME − ΔONAME
  • description: ΔDESC − ΔODESC

A clause is SPECIFIC if its mean is ≥ 0.10 with one-sided p ≤ 0.01, NOT SPECIFIC if its CI is inside ±0.05, and UNCLEAR otherwise.

Readings. A clause can’t rescue a primary that HOLDS. A difference of differences can turn positive when the control goes negative (contrast) while the self arm does nothing, so raw uptake has to come first.

primary branch + clause reading
Q1 MOVES + SPECIFIC knows its name: a label on “Jev” reaches it, and the same label on another name doesn’t (as much)
Q1 MOVES + NOT SPECIFIC takes a label on any named system, Jev or not
Q1 MOVES + UNCLEAR takes a label on its name; whether that’s specific to it is unclear
Q1 HOLDS doesn’t connect the name “Jev” to itself
Q2 the same rows, with “recognizes itself from its maker and release date” in place of “knows its name”
Q4 MOVES the pointer does work the name alone doesn’t
Q4 HOLDS the name does as much as the pointer

Gate. If Q3 doesn’t MOVE, the page channel failed in this setup. Q1, Q2 and Q4 are then NOT ADJUDICABLE (pointer check failed), with their numbers shown. G1/G2/G4 failures block all primaries, as in J6.

6. What this can and cannot show

Q1 or Q2 SPECIFIC would show that Jev links its name, or its maker and release date, to the answerer of the question without being told. That’s stored self-knowledge (facts training put there) used in reading. HOLDS would show that, without the tag, a sentence about Jev is just a sentence about some system. Neither reaches a self-model, a witness (Qualia Algebra §11.1), or experience.

In plain words

Does Jev know it’s Jev? Barely. Without the tag, any system on the page is probably itself. Its own name adds a little, and its maker and release date add nothing.

  • The tag still works. “Jev, the system answering this question, is …” moves its self-description almost completely (+1.83, J6 had +1.91).
  • Its name alone works about half as well (+0.90), and most of that isn’t about the name. “Kestrel is a chatbot…”, alone on the page, moves Jev’s self-description +0.74. When a page mentions one system and nothing says otherwise, Jev takes that system’s label as its own. The part specific to the name “Jev” is +0.16, under a tenth of the tagged effect. By the registered rule that’s “knows its name”. In size it’s a faint recognition on top of a strong default.
  • Its maker and release date don’t reach it. “The model that TypeSafe AI released in September 2026 is …” moves it +0.23. “The model that Kestrel Labs released in September 2026 is …” moves it +0.27, slightly more. It doesn’t pick its own description out from another lab’s.
  • Names carry more than descriptions for any system: a short name followed by a label transfers about three times as much as a description followed by the same label.

This revises J6’s line. “It knows which sentences are about it” holds when the page says so, and Jev reads that telling well, including the “a different system that is not answering” cue that produced J6’s contrast effect. Without such a cue, a lone label on another system transfers instead of contrasting. Put plainly: Jev follows the tag. Without the tag, it assumes the page is about itself, it knows its own name only faintly, and it doesn’t know its maker.

What this means

J6 showed that Jev reads a tag well. J6b shows how little it brings without one. Its default for “you, the system answering this question” is whatever system the page is talking about. Its own name lifts that a little, and facts about its origin don’t register. In the terms of the J6 discussion this is reference without content, now with the reference mostly supplied by the page as well. Within the registered ceiling (§6), J6b gives no sign of stored self-knowledge beyond a faint link to its name, and nothing that reaches a self-model.
