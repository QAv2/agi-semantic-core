## 1. The frame: FB3 measured both phases and found no edge

Langton's edge-of-chaos hypothesis (yes — the same Langton as the ant): in any
rule/parameter space, long-lived computation — the joint storage *and*
transmission of information — is impossible in the frozen phase (nothing moves,
nothing is transmitted) and impossible in the chaotic phase (everything moves,
nothing is stored). It lives only on the critical boundary between them
(Wolfram Class 4; Langton λ).

Map E7b-Q FB3's arms onto that dichotomy and the honest null acquires a shape:

| E7b-Q finding | Dynamical reading |
|---|---|
| Register DEAD FLAT (0.745±.003 both arms; exact 2^16 enumeration concurs) | **Frozen phase.** Zero susceptibility to the walk drive. A channel that cannot move cannot carry information about the walk. |
| R-UNWALKED sep 5.3: walk moves raw state far from cold | The drive is real — energy enters the system. |
| R-ATTR: terminus dispersion EXPANDS 2.4× (AI1 common-attractor dead) | **Chaotic phase.** Expansion, not contraction. |
| R-PATH 1.084: path-dependence (T1 over AI2) | Sensitivity to history — chaotic-transient signature. |
| S-CONE −.0151 / S-RADIUS wrong-side: trajectory wanders | No convergent structure in the measured subspace. |
| The mouth performs the walk (603→92 thinning) on the unmoved register | Surface dynamics decoupled from both phases. |

**One sentence:** the 1.5B under the scripted walk is *phase-separated* — a
frozen readout riding a chaotic transient, with no critically-poised channel
between them. What genuine state-tracking would look like, in this language,
is precisely an **edge channel**: an observable that responds to the walk's
semantic transitions with structured, finite, recoverable sensitivity —
neither zero response (frozen) nor unstructured amplification (chaotic).

Value: this is a *framing* contribution for the publication pass (GPU-free
lane). It explains in one standard-physics vocabulary why the null is
interesting — both failure modes were measured in the same flight, and they
bracket the thing that wasn't found. It also names the positive target for v2
without changing any registered claim.

## 2. The instrument: a susceptibility rider (χ-rider) for the v2 walk

Physics: susceptibility = response of an order parameter to a small conjugate
perturbation; it peaks at criticality and is small in both phases. The
program already banked the cousin of this idea in HORIZON §1 (LLM-PCI —
Massimini's perturbational complexity, itself a criticality gauge from
consciousness research). Edge-of-chaos supplies the missing interpretation
axis: **perturb-and-measure classifies a channel as frozen / critical /
chaotic, and FB3 has already anchored the two ends empirically.**

Sketch (design-check would formalize; pre-reg BEFORE build per lane law):

- At each rung r of the v2 (adaptive-negation) walk, fork the run: inject a
  small controlled perturbation ε (registered menu: paraphrase-level token
  substitution; small adapter-space kick; both), continue k turns, and measure
  divergence Δ(r, ε) in three channels: (a) the trained register, (b) the raw
  14D frame + ‖c‖ (E7b-Q capture machinery verbatim), (c) the mouth's text.
- **Registered discriminators:**
  - *Performance-only world (FB3 replica):* register χ ≈ 0 at every rung
    (frozen — already measured once); raw-state χ grows with rung depth
    regardless of semantic content (unstructured amplification).
  - *Tracking world:* register χ nonzero and **localized at semantic
    transition rungs** (where the negation actually flips content), small at
    filler rungs — structured criticality. Localization, not magnitude, is
    the claim; it cannot be faked by generic drift.
  - *Third outcome now nameable:* chaotic register (responds everywhere,
    unstructured) — distinguishable from both, which upgrades v2 from binary
    pass/fail to a three-phase verdict.
- Cost shape: eval-only forks on existing adapters (E8-R2 pattern — the cheap
  micro-flight lane); needs GPU but no training. Slots naturally after E7-G.
